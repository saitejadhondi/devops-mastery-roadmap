# Real World DevOps Projects

## Portfolio Projects That Simulate Production Environments

> Learning tools is important.
>
> Building projects is what gets interviews.
>
> Most companies want engineers who can:
>
> * Build CI/CD pipelines
> * Deploy applications
> * Automate infrastructure
> * Monitor systems
> * Troubleshoot failures
>
> These projects combine all previous chapters into practical real-world implementations.

# 🔥 Interview Questions

### Why Build DevOps Projects?

To demonstrate practical implementation skills.

---

### What Is A Good Beginner DevOps Project?

Static website deployment using AWS S3 and CloudFront.

---

### What Is A Good CI/CD Project?

GitHub Actions pipeline for automated build, test, and deployment.

---

### What Is A Good Docker Project?

Containerizing and deploying a web application.

---

### What Is A Good Kubernetes Project?

Deploying and scaling containerized applications using Deployments and Services.

---

### Why Use Terraform?

To automate infrastructure provisioning using code.

---

### Why Use Prometheus And Grafana?

To collect, visualize, and alert on infrastructure and application metrics.
